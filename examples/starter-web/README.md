# قالب بسيط: استخدام @mahjoob/core في صفحة ويب

أقل مثال ممكن لتشغيل النواة: صفحة واحدة، بلا أدوات بناء. تفحص صورة تختارها وتعرض القرار.

## التشغيل
1. نزّل النموذجين (مرة واحدة):
   ```
   python get_models.py
   ```
2. شغّل خادمًا محليًا من هذا المجلد (ملفات الوحدات لا تعمل بفتحها مباشرة من القرص):
   ```
   python -m http.server 8000
   ```
3. افتح `http://localhost:8000` واختر صورة.

## كيف يعمل
- `index.html`: خريطة استيراد (import map) تجلب `@mahjoob/core` من npm عبر jsDelivr، وتحمّل onnxruntime-web.
- `main.js`: أربع خطوات: تحميل النموذجين، بناء المحلّل، إنشاء `ImageGuard`، فحص الصورة.

## قبل أن تبني عليه
- **الدقة ليست 100%**: انظر README الحزمة (حوالي 7% من وجوه الإناث الواضحة مرّت في قياسنا).
- الصورة تبقى مموّهة حتى يصدر القرار. هذا ما نوصي به في أي واجهة: **أخفِ أولًا ثم اكشف**.
- أخطاء التحميل أو التحليل = حجب (Fail-Closed). لا تعكس هذا السلوك.
- للتطبيقات الكبيرة استخدم أداة بناء (Vite وغيرها) و`npm install @mahjoob/core onnxruntime-web`.
- مثال أكمل: مجلد `extension/` (إضافة متصفح كاملة).
