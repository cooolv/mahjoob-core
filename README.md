# Mahjoob Core (نواة الحجب)

نواة مفتوحة المصدر تساعد مطوّري إضافات المتصفح وتطبيقات أندرويد على **حجب صور جنس معيّن**
(صور عادية، مصغّرات فيديو، وإطارات داخل الفيديو) مع **معالجة محلية بالكامل على الجهاز**.

## الحزم

| الحزمة | الحالة | الوصف |
|---|---|---|
| `packages/core-js` | v0.1 | محرك القرار + حارس الصور + حارس الفيديو (TypeScript) |
| `packages/core-android` | مخطط | نفس المنطق لأندرويد (Kotlin) |

## المبادئ

1. **Fail-Closed**: أي خطأ أو مهلة أو غموض => حجب (في الوضع الصارم، وهو الافتراضي).
2. **الخصوصية**: لا رفع للصور ولا حسابات ولا تتبّع. المعالجة على الجهاز فقط.
3. **النواة مستقلة عن النموذج**: تُمرَّر لها واجهة `PersonAnalyzer` وتنفّذها أنت بنموذجك (ONNX وغيره).
4. **صدق القياس**: لا ندّعي دقة لم تُقَس. الاختبارات الحالية تستخدم محلّلات وهمية للتحقق من المنطق فقط.

## حدود معروفة

- لا يوجد حجب بدقة 100%: صور بلا وجوه، زوايا الجسم، الإضاءة، الرسوم، والصور الصغيرة تقلّل الدقة.
- النواة لا تتضمن نموذجًا. ترخيص النموذج الذي تختاره مسؤوليتك (بعض النماذج الشهيرة غير تجارية).
- الفيديو: التغطية تعتمد على أخذ عيّنات دورية، فقد يمرّ إطار بين عيّنتين. قلّل الفاصل لتحسين الأمان على حساب الأداء.

## البدء

```bash
cd packages/core-js
npm install
npm test
npm run build
```
