# سيف فيو (SafeView) — إضافة Chrome / Edge / Brave

إضافة مفتوحة المصدر تحجب صور جنس تختاره (إناث، ذكور، أو **كل الأشخاص**) داخل المتصفح،
مبنية على نواة المشروع `mahjoob-core` (كاشف الوجوه YuNet + مصنّف الجنس gender-v1).

**الخصوصية:** كل المعالجة على جهازك. لا حسابات ولا تتبّع ولا خوادم تابعة للمشروع.
تنبيه صريح: للصور القادمة من مواقع أخرى (بلا CORS) تجلبها الإضافة بنفسها لفحصها، فيرى ذلك الموقع طلبًا إضافيًا للصورة.

## التثبيت (من GitHub، بلا أدوات)
1. في المستودع افتح **Actions** ثم **Extension (بناء إضافة سيف فيو)** ثم **Run workflow**.
2. بعد ✅ افتح التشغيل ونزّل الملف **safeview-extension** من قسم Artifacts، وفكّ ضغطه.
3. في Chrome افتح `chrome://extensions` وفعّل **Developer mode**.
4. اضغط **Load unpacked** واختر المجلد الذي فككته (الذي يحوي `manifest.json`).
5. اضغط أيقونة الإضافة واختر ما تريد حجبه.

## كيف تعمل
- كل `<img>` و`<video>` **مخفي بـCSS من أول لحظة** حتى يصدر القرار (Fail-Closed). إن تعطّلت الإضافة أو فشل تحميل النماذج تبقى الصور مخفية/محجوبة.
- الصورة المسموحة تظهر، والمحجوبة تُستبدل بمربع رمادي بنفس المقاس (لا تمويه).
- الفيديو يبدأ مغطّى، ويُكشف بعد إطارين آمنين متتاليين، ويُغطّى فورًا عند التقديم أو التأخير. فيديو لا يمكن قراءة إطاراته يبقى مغطّى.
- الصور الأصغر من 40 بكسل وملفات SVG والصور التالفة تُسمح دون فحص.

## حدود معروفة (v0.1) — اقرأها
- **الدقة:** في قياسنا على 200 صورة FairFace جديدة مرّت نحو **7%** من وجوه الإناث الواضحة دون حجب (المجال 3.4–13.7%)، وحُجب نحو 28% من وجوه الذكور خطأ. على صور الإنترنت المتوقع أسوأ. لا ضمان 100%.
- الصور التي لا يُكتشف فيها وجه **تمرّ** (أجسام بلا وجه، وجوه صغيرة جدًا، رسوم...). وضع **كل الأشخاص** أضمن لكنه مقيّد بالكاشف نفسه.
- **غير مغطّى بعد:** صور خلفية CSS، عناصر داخل Shadow DOM، `<canvas>`، `<svg>` المحتوي صورًا، وصور الإطارات خارج مداخل http/https.
- لا يوجد اختبار على مواقع حقيقية كبيرة (يوتيوب، فيسبوك...) بعد.
- الواجهة عربية فقط حاليًا.

## ما اختُبر وما لم يُختبر
- اختبار آلي في Chromium حقيقي بإضافة محمَّلة فعلًا (service worker وoffscreen وcontent script) بمحلّل **وهمي**:
  التغطية قبل القرار، فحص الصور من نفس الأصل ومن أصل آخر وdata:، الصور المضافة لاحقًا وتغيّر `src`، الفيديو والتقديم،
  تغيير الهدف، التعطيل (عام وللموقع)، النافذة المنبثقة، وسلوك الحجب عند فشل تحميل النماذج. (25 فحصًا نجحت)
- **لم يُختبر هنا:** النماذج الحقيقية وonnxruntime-web الحقيقي داخل الإضافة. أول تشغيل حقيقي سيكون عندك.

## تشغيل الاختبار محليًا (للمطوّرين)
```
pip install playwright pillow && playwright install chromium
# ابنِ نسختين من الإضافة بـonnxruntime وهمي ثم:
DIST_OK=... DIST_FAIL=... python3 extension/test/test_extension.py
```

## البناء يدويًا
```
cd packages/core-js && npm install && npm run build && cd ../..
bash extension/scripts/fetch-assets.sh   # ينزّل النماذج وonnxruntime-web
bash extension/scripts/assemble.sh       # الناتج في extension/dist
```
